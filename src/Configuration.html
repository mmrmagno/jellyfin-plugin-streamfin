Movies & TV

Make a free account on themoviedb.org, then go to Settings > API. The short API key and the long read access token both work. The channel stays hidden until a key is set.

Music

When a song or album also exists as a clean edit, hide the edit and play the original.
Leave empty for the default. Lossless FLAC, CD quality or better. Only a plain https address is accepted.
Songs you play are kept on this server, so skipping within a song and playing it again are instant. The least recently played make room when it is full. 0 turns it off.
Starred albums are saved here as tagged FLAC files, one folder per artist and album, so they play offline and in any music app. Use a folder that belongs to a Jellyfin music library and that Jellyfin can write to. Existing files are never replaced. Albums are saved slowly, one song every 20 seconds, to stay within the catalog's limits. Leave empty to save nothing.

    Subsonic apps

    For Symfonium, Feishin, Tempo, play:Sub and other Subsonic apps. In the app, use the server address , the Jellyfin username, and the app password below. The Jellyfin password does not work there. A new password replaces the old one.
    Some apps, Amperfy among them, ask for MP3 by default. With this on they get the original FLAC instead, which sounds better and seeks faster. A data saving limit in the app, such as 128 or 320 kbps, still gets a smaller converted file.
